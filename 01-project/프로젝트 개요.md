# 1. 프로젝트 소개

## 1.1 프로젝트 개요

SatelliteView는 위성 이미지의 등록, 관리, 검색 및 거래 과정을 지원하는 백엔드 프로젝트이다.

관리자는 위성 이미지를 업로드하고 위치, 촬영일, 해상도, 구름량, 센서 등 다양한 메타데이터를 관리할 수 있으며, 사용자는 이러한 메타데이터를 기반으로 원하는 위성 이미지를 검색하고 상세 정보를 조회할 수 있다.

또한 사용자는 등록된 위성 이미지에 대해 구매 문의를 등록하거나 원하는 조건의 신규 위성 이미지에 대한 견적을 요청할 수 있으며, 관리자는 각 문의를 관리하고 처리 상태를 관리한다.

이를 통해 위성 이미지 관리부터 검색, 구매 문의 및 견적 요청까지 하나의 서비스에서 처리할 수 있는 위성 이미지 중개 플랫폼의 백엔드를 구현하는 것을 목표로 한다.

## 1.2 주요 기능

### 공통

| 기능 | 설명 |
|------|------|
| 로그인 | JWT Access Token 및 Refresh Token 기반 인증 |
| 로그아웃 | Access Token 및 Refresh Token 무효화 |
| 위성 이미지 목록 조회 | 등록된 위성 이미지 목록을 최신순 또는 정렬 기준에 따라 조회 |
| 위성 이미지 검색 | 위치, 촬영일, 해상도, 구름량 등 다양한 메타데이터를 활용한 검색 및 필터링 |
| 위성 이미지 상세 조회 | 선택한 위성 이미지의 상세 정보 및 메타데이터 조회 |

### 관리자

| 기능 | 설명 |
|------|------|
| 위성 이미지 등록 | 위성 이미지를 업로드하고 메타데이터와 함께 등록 |
| 비공개 이미지 조회 | 숨김 처리된 위성 이미지 조회 |
| 위성 이미지 수정 | 위성 이미지와 메타데이터 수정 |
| 위성 이미지 공개/숨김 | 일반 사용자에게 노출 여부를 변경 |
| 위성 이미지 삭제 | 더 이상 사용하지 않는 위성 이미지 삭제 |
| 메타데이터 관리 | 위성 이미지 메타데이터 등록, 수정 및 삭제 |
| 구매 문의 관리 | 구매 문의 조회 및 처리 상태 관리 |
| 견적 요청 관리 | 견적 요청 조회 및 처리 상태 관리 |

### 사용자

| 기능 | 설명 |
|------|------|
| 회원가입 | 사용자 계정 생성 |
| 회원 탈퇴 | 사용자 계정을 탈퇴 처리 |
| 구매 문의 등록 | 등록된 위성 이미지에 대한 구매 문의 등록 |
| 견적 요청 등록 | 특정 지역이나 조건의 신규 위성 이미지에 대한 견적 요청 등록 |
| 문의 내역 조회 | 구매 문의 및 견적 요청 진행 상태 조회 |

# 2. 프로젝트 추진 배경

기존의 단순 CRUD 중심 프로젝트에서 벗어나 실제 서비스와 유사한 비즈니스 흐름을 가진 백엔드 프로젝트를 구현하고자 하였다.

위성 이미지 서비스는 다양한 메타데이터를 기반으로 이미지를 탐색하고, 원하는 이미지 또는 특정 지역의 추가 이미지에 대해 상담 및 견적을 진행하는 업무 흐름을 가진다.

본 프로젝트는 이러한 흐름을 단순화하여 구현함으로써 파일 관리, 데이터 모델링, 검색 기능, 비즈니스 로직, 관리자 기능 등을 포함한 실무형 백엔드 개발 경험을 목표로 한다.

---

# 3. 프로젝트 목표

본 프로젝트의 목표는 다음과 같다.

- NestJS 기반 백엔드 서비스 구현
- TypeScript 기반 서버 개발 경험 확보
- PostgreSQL 기반 데이터 모델링
- Amazon S3를 활용한 이미지 파일 관리
- 메타데이터 기반 상세 검색 기능 구현
- JWT 기반 인증 및 권한 관리
- Swagger 기반 API 문서 자동화
- Jest 및 Supertest를 활용한 테스트 코드 작성
- Docker 기반 개발 환경 구성
- AWS EC2 배포
- GitHub Actions 기반 CI/CD 구축
